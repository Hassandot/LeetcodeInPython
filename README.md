# LeetCode in Python

A comprehensive collection of LeetCode problem solutions implemented in Python, organized by difficulty level.

## 📋 Overview

This repository contains solutions to various LeetCode problems, carefully organized and implemented in Python. It serves as a learning resource for algorithm and data structure practice, interview preparation, and mastering problem-solving techniques.

- *(Medium and Hard sections can be added as you expand the repository)*

## 🚀 Getting Started

### Prerequisites
- Python 3.7 or higher

### Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/Hassandot/LeetcodeInPython.git
   cd LeetcodeInPython
   ```

2. Navigate to the difficulty level you want to explore:
   ```bash
   cd Leetcode-easy
   ```

3. Review the solutions and study the approaches used
